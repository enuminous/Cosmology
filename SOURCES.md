# Primary sources and provenance

This package defines a new frozen *model instance*, not a new experimentally established theory. Sources were inspected for formulation and reproducibility; none supplies empirical validation of this EFMW specialization.

1. Matthew Chenoweth Wright / enuminous, EFMW-Lagrangian, C1 candidate. Parent commit `2e392b9fb5bbfa35667cd562787e23cadcc1623f` (16 October 2026), candidate version 1.0.0 dated 13 October 2026. Public research repository, not a peer-reviewed cosmology result. Exact parent specification and conventions are retained under sources. https://github.com/enuminous/EFMW-Lagrangian/blob/2e392b9fb5bbfa35667cd562787e23cadcc1623f/candidate/CANDIDATE.md ; https://github.com/enuminous/EFMW-Lagrangian/blob/2e392b9fb5bbfa35667cd562787e23cadcc1623f/candidate/conventions.json . The matter extension and one-scalar restriction are explicit new choices here; the parent catalogue is not asserted to imply them uniquely.

2. CLASS public code, commit `814ce59c380a5cccd0bed1747a384ff7bfc1f9cf` (4 October 2026), version 3.4.1. https://github.com/lesgourg/class_public/tree/814ce59c380a5cccd0bed1747a384ff7bfc1f9cf . The minimal build inputs were obtained from this exact revision and verified against their Git blob hashes; sources/CLASS-source-manifest.json records them. The adapter changes source/background.c (quadratic potential and derivatives) and source/input.c (refresh explicit initial data after shooting). Perturbations, atomic physics and neutrino modules are unchanged. Upstream authors retain their code attribution and licensing; obtain that source from upstream.

3. D. Blas, J. Lesgourgues and T. Tram, *The Cosmic Linear Anisotropy Solving System (CLASS) II: Approximation schemes*, JCAP 07 (2011) 034. Peer-reviewed journal article; preprint first submitted 14 April 2011, arXiv v3 revised 17 August 2011. https://doi.org/10.1088/1475-7516/2011/07/034 ; https://arxiv.org/abs/1104.2933 . This is the primary description of numerical approximation schemes, not a certificate for the present adapter.

4. C.-P. Ma and E. Bertschinger, *Cosmological Perturbation Theory in the Synchronous and Conformal Newtonian Gauges*, Astrophysical Journal 455 (1995) 7-25. Peer-reviewed journal article; preprint submitted 11 June 1995. https://doi.org/10.1086/176550 ; https://arxiv.org/abs/astro-ph/9506072 . Primary reference for gauge conventions and the coupled Einstein-Boltzmann species hierarchy.

5. T. Chiba, *Slow-Roll Thawing Quintessence*, Physical Review D 79 (2009) 083517; erratum D80 (2009) 109902. Peer-reviewed research; arXiv first submitted 23 February 2009, v5 revised 25 September 2009. https://doi.org/10.1103/PhysRevD.79.083517 ; https://arxiv.org/abs/0902.4037 . Relevant established thawing-scalar context. The present calculation integrates the exact quadratic field equations instead of using its approximate w(a) formula.

Numerical values are computed in this package from explicitly chosen inputs. They are not borrowed posterior constraints. Primary-source access through the repository content service supplied pinned files; the ordinary web page fetch was unavailable for the pinned GitHub views. No claim is based solely on a search snippet. There is no new journal article, submission or Lean certificate associated with this package.
