# C1Q observational execution plan v1

Recorded 2026-10-25 before evaluating an observational likelihood. This is an internal prospective execution record, not an independently registered or blinded experiment.

The source model is Cosmology commit f457a1fc414257d5e4d2ddbeb8985db2cb714363. The original physical freeze and original outputs remain unchanged. Acquisition is pinned in data_manifest.initial.json; data_manifest.json adds verified SHA256 receipts. The same complete released covariance and the same nuisance treatment apply to both models.

1. Reproduce the frozen numerical background checks, verify source hashes, and build the pinned CLASS adapter. Compute the immutable fiducial C1Q and matched LambdaCDM point likelihoods, profiling the common supernova absolute-magnitude offset. This comparison has no fitted cosmological parameters and is not the family-selection statistic.
2. Fit the two separately named families with the exact uniform bounds in the original protocol. Stage-1 distances contain no information about primordial amplitude or tilt; their independent priors integrate out. Reionization is retained at the fiducial value for distance calculations and its effect on the drag ruler is checked across the prescribed interval. No external sound-horizon or H0 prior is introduced.
3. Use physical thermal-neutrino evolution and the quadratic scalar equations, not a CPL surrogate. The sound horizon is obtained from the pinned CLASS thermodynamics calculation. An interpolated numerical surrogate may accelerate repeated evaluations only after independent direct-solver validation, with target relative errors below 2e-6 for distances and the sound horizon and changes of computed chi-square below 0.01 at validation points. An unvalidated surrogate cannot support a reported fit.
4. The default optimization is a fixed seeded multistart bounded search over common physical parameters and log10(mu) for C1Q. Use the same method and maximum number of objective calls for both models and every mock. Freeze exact algorithm settings, training grids, validation seeds, and software hashes in implementation_lock.json before fitting. Convergence failures remain failures and are not silently dropped from calibration.
5. Once fits converge, sample the declared posterior and report convergence diagnostics; do not label an unconverged chain a posterior result. The 200 synthetic realizations use numpy SeedSequence(20261016).spawn(200), full observational covariance, the observed redshifts and selection, and the fitted LambdaCDM mean. This is a likelihood-level parametric bootstrap conditional on the released data selection, not a new end-to-end survey simulation. Both families and the common magnitude offset are refitted on each realization. Report the original T statistic, p_MC, binomial uncertainty, and finite resolution floor.
6. Keep the Planck TT/TE/EE plus lensing evaluation separate from training. It requires the full likelihood, compatible dependencies and nuisance treatment; compressed constraints are not a substitute. A future independent distance/growth release has not yet been selected and cannot be represented as an executed holdout.

Stopping and interpretation: physical/numerical failures are preserved; implementation failures may be corrected with a recorded code revision and rerun checks. A missing likelihood or resource is a documented incomplete stage, not evidence against the physics. Failure of any screening condition precludes a positive model-development claim. A point-model failure does not reject the full fitted C1Q family or all EFMW models.
